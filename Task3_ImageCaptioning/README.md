# Image Captioning AI

## Description
This project is an AI-based Image Captioning system developed using Python and the BLIP pre-trained model. It automatically generates captions for images.

## Features
- Generates captions for images
- Uses a pre-trained BLIP model
- Simple and easy to use

## Technologies Used
- Python
- Transformers
- PyTorch
- Pillow

## Output

Generated Caption:
a cat sitting in a bowl with its mouth open
